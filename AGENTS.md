# Agent guidelines

All guidance for working on this repository lives in
[`docs/development/agents.md`](docs/development/agents.md). Read it before doing any work.

All documentation, including guidance for agents, lives under `docs/`. Don't add guidance to this file: the section
below only points review agents to the review guidelines.

## Code Review Rules

When you review a change, apply the `codereview_guideline.md` file at the repository root. Also apply each
`codereview_guideline.md` file in a directory that contains a changed file, directly or in a subdirectory. We generate
these files from `docs/development/`; see `docs/development/code-review.md`.
