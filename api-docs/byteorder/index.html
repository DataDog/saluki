Crate byteorder 

Source
Expand description

The subset of the byteorder 1.x API that our dependencies use.

The [patch.crates-io] section of the workspace manifest replaces crates.io byteorder with this crate. It keeps upstream’s names, signatures, and behavior, but only for the items that our dependencies use. When a dependency needs an item that’s missing here, the build fails instead of behaving differently, and the item can be added then.

The API and behavior are derived from byteorder 1.5.0 by Andrew Gallant, licensed under Unlicense OR MIT.
