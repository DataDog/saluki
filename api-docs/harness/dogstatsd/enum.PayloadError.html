Expand description

The first drop rule a serialized DogStatsD payload violates, tagged with the 0-based index of the offending message among the payload’s \n-split segments. Blank segments are counted in the index but are never malformed.

One variant per Agent drop rule, across all three message types. The metric T timestamp rule is intentionally absent. See the note in classify_metric.
