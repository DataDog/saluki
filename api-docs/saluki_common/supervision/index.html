Contract for supervised processes.

This module holds the contract a supervised process implements – Supervisable and the types in its signature – while the machinery that drives it (supervisors, restart strategies, the supervision tree) lives in saluki-core. The split mirrors http/hyper: the contract is a leaf that anything can implement, so it sits low enough for crates beneath saluki-core to describe background work without depending on the engine that runs it.

Most code should reach for these through saluki_core::runtime, which re-exports them alongside the supervisor itself.
