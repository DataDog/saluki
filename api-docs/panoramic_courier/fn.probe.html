pub async fn probe(address: &Address, limit: Duration) -> Result<(), Error>
Expand description

Checks that something accepts a connection at address.

A tcp, http or grpc probe opens a TCP connection and closes it. A unix probe connects to the stream socket, and a unixgram probe connects a datagram socket to it, which fails unless a socket is bound at the path. A pipe probe opens the named pipe, and counts a pipe that is busy with other clients as present.

limit bounds the call, but a name lookup it cuts short keeps running on its blocking thread until the resolver answers.

§Errors

Fails with Error::Unsupported for a udp address, which a probe cannot confirm, and for a socket or pipe this OS does not have. Fails with Error::Target when nothing accepts, and Error::TimedOut when limit passes.
