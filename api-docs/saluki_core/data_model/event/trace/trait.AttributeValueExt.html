Saluki’s accessors for AttributeValue.

AttributeValue is a type alias for a generic type from another crate, so these accessors are on a trait. Import the trait to call them.

fn as_float(&self) -> Option<f64>

Returns the inner float if this is a Float variant.

Returns Some only when the stored variant is Float. For numeric semantic tags where the source may store an integer (for example, sampling priority, _sample_rate, _top_level), use as_num instead.

fn as_num(&self) -> Option<f64>

Returns a numeric value as f64 for either Float or Int variants.

Use this when the caller only needs a number and doesn’t care whether the stored type is integral or floating-point (for example, sampling priority).
