Enum SalukiValues 

Source 
pub enum SalukiValues {}
Expand description

Selects the concrete types behind attribute values: text is a [MetaString], bytes are a Vec<u8>, arrays are a Vec<AttributeValue>, and key/value lists are a KeyValueList.

It is only used as a type parameter, so it has no values.
