Expand description

A remote agent’s local configuration, loaded before it connects to the Datadog Agent.

This is the configuration from local sources only, such as a configuration file and environment variables. It decides whether the remote agent runs standalone, and how it reaches the Datadog Agent. It then becomes the remote agent’s AuthoritativeConfiguration, either by layering the Datadog Agent’s configuration stream on top of it or, in standalone mode, on its own.

fn connect( self, config_stream: Receiver<ConfigUpdate>, ) -> impl Future<Output = Result<(R::AuthoritativeConfiguration, R::ConfigurationUpdates), GenericError>> + Send

Selects the Datadog Agent’s configuration stream as the configuration authority.

Waits for the initial snapshot from config_stream, and returns the resulting configuration along with the updates that apply each later snapshot.

§Errors

If the stream closes before its initial snapshot, or the resulting configuration is invalid, an error is returned.
