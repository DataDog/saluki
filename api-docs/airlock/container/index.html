Module container 

Source
Expand description

Named containers in a case scope: create, start, observe, stop and remove.

Creating and starting are separate, so files can be placed between them. A container joins the case network under its participant name, mounts the case volume when its scope has one, and can publish TCP ports on the runner’s 127.0.0.1. Docker chooses each host port, and Container::published_port reads it back after start.
