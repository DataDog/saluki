pub async fn wait(&self, deadline: Instant) -> Result<i64, GenericError>

Waits for the container to stop running and returns its exit code. Call it after Self::start.

Death by signal n is reported as code 128 + n.

§Errors

Returns an error if Docker cannot report the exit, for example because the container was removed, if the container never ran, because it was not started or its start failed, or if deadline passes before the container exits.

pub async fn stop( &self, grace: Duration, deadline: Instant, ) -> Result<(), GenericError>

Stops the container: signals its main process, then kills it if it is still running after grace.

Docker counts the grace in whole seconds, so a fraction of a second is rounded up.

A container that is already stopped or gone counts as stopped.

§Errors

Returns an error if Docker fails to stop the container, or if deadline passes first.

pub async fn exec( &self, command: Vec<String>, stdin: Option<Bytes>, deadline: Instant, ) -> Result<ExecOutput, GenericError>

Runs command in the running container and waits for it to exit.

With stdin, the bytes are written to the command’s standard input, which is then closed. The command may exit without reading them all. Without it, the command has no standard input. A nonzero exit code is a result, not an error.

§Errors

Returns an error if Docker cannot run the command, if its output cannot be read, if Docker does not report its exit code, or if deadline passes before the command exits.

pub async fn place( &self, root: &str, archive: Archive, deadline: Instant, ) -> Result<(), GenericError>

Places every file of archive under root, such as /, in the container’s filesystem.

This works whether or not the container is running, so files can be placed between create and start. A file whose path lies on a volume the container mounts is written to that volume.

§Errors

Returns an error if the archive cannot be finished, if Docker refuses to extract it, or if deadline passes first.

Source

pub async fn read_file( &self, path: &str, deadline: Instant, ) -> Result<Option<Vec<u8>>, GenericError>

Reads the file at path in the container’s filesystem, or returns None if nothing is there.

§Errors

Returns an error if the container does not exist, if Docker cannot copy the path out, if the path is not a regular file, or if deadline passes first.
