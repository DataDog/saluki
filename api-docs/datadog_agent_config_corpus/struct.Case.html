pub fn check_origin(&self) -> &str

The stable origin of the case’s checks: what produced them, stripped of the naming a schema bump reshuffles (case.md §3.2, §3.2.1).

The baseline, behavior and unknown groups keep the case name. A depth case drops the --<key> suffix of a bisection part, leaving depth-<variant>. The batched groups (breadth, unsupported, excluded) drop the section batch and any --<key> suffix, leaving <group>-<source>, since a recorded read’s own key member already names the exact setting. This is an assertion identity for replay expectations, not a runtime case filter or a category grouping.
