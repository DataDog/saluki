pub fn former_names<'a>(
    schema: &'a IndexMap<String, FieldInfo>,
    modeled: &HashSet<&str>,
) -> Vec<FormerName<'a>>
Expand description

Every former name of every setting in schema, grouped by setting and highest priority first within a setting.

A former name’s environment variable is derived for a modeled setting, which is the only kind the environment reader reads.

Panics when a former name is a schema path, or a setting or another former name contains or holds it, since the file reader could not tell which one a key addresses.
