Source

pub fn serve<R: Rng + ?Sized>( &self, n: usize, rng: &mut R, ) -> Result<Vec<Context>>

Serve n contexts: for each slot sample a kind, mint a fresh one while that kind is under its cap, else draw an existing one of that kind. The whole operation holds the lock, so concurrent requests never race on rng or overshoot a cap.

§Errors

Returns an error if context_source.yaml cannot be read on the first call.
