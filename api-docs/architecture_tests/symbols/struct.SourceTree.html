pub fn aliases( &self, crate_root: &Path, names: &BTreeSet<String>, ) -> Result<BTreeSet<String>, Error>

Collects aliases of names from this tree.

An alias binds a name through an item mentioning a guarded name or another alias. At file and inline-module scope, the scan includes:

  • use, type, and extern crate items with visibility other than private or pub(self)
  • private bindings of those kinds at the top level of crate_root, accessible to descendant modules
  • macro_rules! definitions, regardless of visibility

Private bindings elsewhere contribute only to same-file alias chains. Bindings inside blocks or macro invocations aren’t collected. Matches ignore Rust scope, so unrelated names can match.

§Errors

Returns an error if crate_root isn’t scanned or an included use item glob-imports a path containing a guarded name or alias. Glob-bound names can’t be enumerated from the import syntax.
