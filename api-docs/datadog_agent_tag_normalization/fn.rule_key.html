pub fn rule_key(key: &str) -> Option<String>
Expand description

Normalizes a configured tag key into the key the intake stores for tags with that key.

Returns None when no stored tag can have that key, which is when it contains :. Such a key must not match anything. The empty key is a valid result: the intake stores :foo and 123:foo with an empty key, so the rule keys ``, 123 and _ all match them.
